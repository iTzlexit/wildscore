`app/assets/data/attributions.json`; regenerate after re-running
`app/tool/prepare_species_photos.dart`.

**All 71 are CC0 or CC-BY** — commercially usable. CC-BY-NC was explicitly
excluded, which matters because it is iNaturalist's most common default.

Tick **Replace?** for any image you want re-sourced or commissioned. The rarest
species have the worst photographs — rare animals are mostly photographed by
camera traps — so start there if any budget appears. See
